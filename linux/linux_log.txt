  SD boot
   
    Package the boot binary image for it including the 
      MPSoC first stage bootloader (FSBL), 
      FPGA bitsteam, and 
      Linux second stage bootloader (u-boot):
     
      petalinux-package --boot --fsbl ./images/linux/zynqmp_fsbl.elf --fpga ./images/linux/system.bit --u-boot
     
   
    Connected usb to vmware through an USB adpter. 
      First select USB 3.1 under USB controller in VM setting
   
    Format SD: Can use GParted
   
    Copy boot files to rootfs to 
     call lsblk to check mounted files
     sudo cp ./images/linux/BOOT.BIN /media/er/BOOT
     sudo cp ./images/linux/image.ub /media/er/BOOT
     sudo cp ./images/linux/system.dtb /media/er/BOOT
     sudo cp ./images/linux/boot.scr /media/er/BOOT
     
     
     sudo tar xvf ./images/linux/rootfs.tar.gz -C /media/er/root/
